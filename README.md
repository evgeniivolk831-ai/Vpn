# GlobalPulse VLESS

Автоматически обновляемая агрегированная подписка из публичных VPN/VLESS-источников.

## Файлы

- `output/GlobalPulse-VLESS.txt` — основная подписка: только VLESS/Reality/TCP узлы, прошедшие E2E-проверку через Xray-core.
- `output/GlobalPulse-TCP-Reachable-VLESS.txt` — резервный список VLESS с подтверждённым TCP reachability, но без полного E2E.
- `output/GlobalPulse-All.txt` — исходные уникальные конфигурации без гарантии работоспособности.
- `output/GlobalPulse-Base64.txt` — Base64-подписка основной E2E-проверенной группы для v2rayNG/NekoBox и совместимых клиентов.
- `output/stats.json` — статистика последнего обновления и уровни проверки.
- `output/e2e-vless.json` — результаты E2E health-check.

GitHub Actions запускает сборку каждый час и также позволяет запустить её вручную. Pipeline работает fail-closed: если E2E-проверка не подтверждает ни одного узла, новая подписка не публикуется. Перед публикацией узлы проходят TCP reachability, затем VLESS/Reality/TCP E2E через Xray-core и HTTP-запрос через локальный SOCKS5. Проверенные узлы сортируются по измеренной latency.

## Источники

Используются только публично опубликованные фиды. Один из источников заявляет почасовое обновление и HTTP-проверку опубликованных узлов; остальные источники могут обновляться с другой частотой. Агрегатор поэтому не обещает, что каждый источник меняется ежечасно. E2E-проверка выполняется с GitHub Actions runner, поэтому она подтверждает работоспособность из точки проверки, а не гарантирует работу через конкретного мобильного оператора.

## Безопасность

Конфигурации принадлежат сторонним операторам. Не используйте неизвестные узлы для чувствительных операций. Репозиторий не содержит приватных ключей или данных закрытых баз.
