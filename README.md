# GlobalPulse VLESS

Автоматически обновляемая агрегированная подписка из публичных VPN/VLESS-источников.

## Файлы

- `output/GlobalPulse-VLESS.txt` — до 100 VLESS/Reality-конфигураций.
- `output/GlobalPulse-All.txt` — до 100 уникальных конфигураций разных поддерживаемых форматов.
- `output/GlobalPulse-Base64.txt` — Base64-подписка для v2rayNG/NekoBox и совместимых клиентов.
- `output/stats.json` — статистика последнего обновления.

GitHub Actions запускает сборку каждый час и также позволяет запустить её вручную.

## Источники

Используются только публично опубликованные фиды. Один из источников заявляет почасовое обновление и HTTP-проверку опубликованных узлов; остальные источники могут обновляться с другой частотой. Агрегатор поэтому не обещает, что каждый источник меняется ежечасно.

## Безопасность

Конфигурации принадлежат сторонним операторам. Не используйте неизвестные узлы для чувствительных операций. Репозиторий не содержит приватных ключей или данных закрытых баз.

## Импорт

Для публичного репозитория постоянная ссылка Base64:

`https://raw.githubusercontent.com/evgeniivolk831-ai/Vpn/main/output/GlobalPulse-Base64.txt`

Если репозиторий приватный, raw-файл не является публичной подпиской для сторонних клиентов.
